# Mohammed Suheb Hashmi - Portfolio

A production-quality personal portfolio website for Mohammed Suheb Hashmi, a Software Developer, Full-Stack Developer, and QA Enthusiast.

## Technology Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Features

- Modern dark theme with subtle gradients and glassmorphism.
- Interactive terminal in the Hero section.
- Comprehensive Projects section with detailed modals.
- Dedicated QA & Testing section with metrics.
- Fully responsive on all devices.
- High performance and smooth scrolling.
- Light/Dark mode support.

## Setup Instructions

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Build for Production:**
   ```bash
   npm run build
   ```

4. **Preview Production Build:**
   ```bash
   npm run preview
   ```

## Customization

The portfolio is designed to be easily updatable via the data files located in `src/data/`:
- `profile.js`: Update personal information, social links, and contact details.
- `skills.js`: Add or modify technical skills.
- `experience.js`: Update work experience.
- `projects.js`: Manage featured projects.
- `education.js`: Update education details.
- `leadership.js`: Manage leadership roles.

Ensure you place a `resume.pdf` file in the `public` folder before deploying.
